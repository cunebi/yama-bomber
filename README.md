# yama-bomber
привет, хочу тебе показать использование моей программы yama. Пожалуйста, дочитай до конца чтобы понять как пользоваться прогой(:
чтобы запустить программу ты должен скачать python, скачать его можно тут: https://www.python.org/downloads/
потом вводи команду pip install pyautogui
после того как ты скачал python ты должен запустить файл который называется main.py
когда ты его запустишь у тебя спросят "сколько окон открыть?" вводи столько, сколько хочешь потоков, у тебя будут запускатся окна бомбера (НЕ РЕКОМЕНДУЮ ВВОДИТЬ СЛИШКОМ МНОГО ПОТОКОВ, ДЛЯ СЛАБЫХ КОМПЬЮТЕРОВ РЕКОМЕНДУЕТСЯ МАКСИМУМ 20 ПОТОКОВ, ДЛЯ НОРМАЛЬНЫХ 50, ДЛЯ МОЩНЫХ 80-120, ЕСЛИ ВЫ ВВЕДЕТЕ СЛИШКОМ МНОГО ПОТОКОВ, ТО ВАШ КОМПЬЮТЕР МОЖЕТ ПРОСТО КРАШНУТСЯ! если он крашнется то уже не мои проблемы, так как я вас предупредил)
и потом у вас спросят цифры (туда вводите номер без +, также бомбер поддерживает ТОЛЬКО украинские номера, на российские, беларусские и тд. не работает, даже не пробуйте)
поздравляем! вы научились пользоваться бомбером, пользуйтесь на здоровье!(: приятной бомбежки гадалок и ваших обидчиков
